## 0. Как обновляется сам Forge

**Одним кликом (основной путь):** скачай `project-forge-vX.Y.Z.zip` (можно оставить в Загрузках)
→ двойной клик по `update-forge.bat` (лежит РЯДОМ с папкой project-forge, НЕ внутри) → Y →
батник сам: выберет **максимальную semver-версию** ZIP → покажет current/package → backup → распакует поверх → `upgrade.bat` (чистка + регенерация Claude/Codex/dashboard) → `./sync.bat` (в корне движка) → проверит все sibling projects, dashboard, Codex compatibility и drift.
Ожидай в конце: `✓ No drift` + номер новой версии.

**Руками (если батника нет):**
```
1. Распаковать zip в project-forge («Заменить все»)
2. .\upgrade.bat
3. ./sync.bat
4. node scripts\check-drift.mjs      ← должно быть "No drift"
5. node scripts\bump-version.mjs --current
```

⚠️ Личные файлы (Forge Helper, заметки) — НИКОГДА не внутри project-forge: папка принадлежит
движку, MANIFEST — закон, всё лишнее удаляется при upgrade.

### AI Studio 4.67 — не новая фаза, а слой внутри 9 фаз

Forge **сохраняет 9 канонических фаз**. AI Studio включается там, где его результат нужен: Ф1 фиксирует AI/visual baseline, Ф2 формирует briefs и prompt packs, Ф3 может раздавать независимые coding-задачи агентам, Ф4 производит и принимает визуальные ассеты, Ф6 готовит store creatives, Ф7 делает visual QA, Ф9 ведёт measured creative A/B. Отдельной Ф10 нет — иначе пришлось бы возвращаться назад после art/QA и ломать линейный phase workflow.

## Быстрые сценарии («что нажать, если…»)

- **Пришёл новый прототип** → Ctrl+Alt+1 (`/phase-1-analyze <папка>`) и дальше по фазам.
- **Вернулся к проекту через неделю** → Ctrl+Alt+9 (`/status`) → жми, что скажет.
- **Игру завернула модерация** → `/audit-requirements` (не изменились ли правила) → `/do фикс по замечанию` → `/phase-7-test` → `/phase-8-release`.
- **Игра опубликована** → Ctrl+Alt+8 (`/phase-9-live`), рейтинг — в таблицу еженедельно.
- **«Проверить всё быстро, без заливки»** → `node scripts/local-stage.mjs <игра> --ai --play`.
- **«Проверь все игры разом»** → «параллельный аудит moderation-auditor'ами по каждой игре в WorkProgress».
