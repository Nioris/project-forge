# Runner Prototype

Скил для создания 2D-раннеров. Раннер — жанр с минимальным управлением и максимальным напряжением. Одна кнопка, одна секунда реакции, бесконечная эскалация.

## R1 40%

Раннер — самый быстрый жанр для прототипирования. Не делай систему магазина и 20 скинов. Прототип = бесконечная генерация, 3-4 типа препятствий, нарастающая скорость, сочная смерть.

## Core: Бесконечная генерация

```javascript
const GAME = {
  speed: 4,            // начальная скорость скролла
  maxSpeed: 12,        // потолок
  acceleration: 0.002, // ускорение за кадр
  distance: 0,
  obstacles: [],
  decorations: [],     // фоновые элементы
};

// Препятствия генерируются по расстоянию
let nextObstacleAt = 300; // пикселей от начала

function spawnObstacle() {
  const types = [
    { w: 30, h: 40, y: GROUND_Y - 40, type: 'low' },      // перепрыгнуть
    { w: 50, h: 20, y: GROUND_Y - 60, type: 'high' },      // присесть
    { w: 20, h: 80, y: GROUND_Y - 80, type: 'tall' },       // прыгнуть высоко
    { w: 40, h: 15, y: GROUND_Y - 30, type: 'gap', isGap: true }, // дырка в полу
  ];

  // Выбор усложняется: сначала только low, потом добавляются остальные
  const available = types.slice(0, Math.min(1 + Math.floor(GAME.distance / 1000), types.length));
  const type = available[Math.floor(Math.random() * available.length)];

  GAME.obstacles.push({
    x: canvasWidth + 50,
    y: type.y,
    w: type.w,
    h: type.h,
    type: type.type,
    passed: false,
  });

  // Следующее препятствие: чем быстрее скорость, тем ближе
  const minGap = Math.max(150, 300 - GAME.speed * 15);
  const maxGap = minGap + 150;
  nextObstacleAt += minGap + Math.random() * (maxGap - minGap);
}
```

**Золотое правило:** расстояние между препятствиями должно давать РОВНО СТОЛЬКО времени, чтобы отреагировать. При скорости 4 — комфортно. При скорости 10 — на грани. При 12 — хардкор.

## Физика персонажа раннера

```javascript
const RUNNER = {
  x: 100,              // фиксированная позиция по X
  y: GROUND_Y,
  vy: 0,
  w: 24, h: 36,
  grounded: true,
  ducking: false,

  // Прыжок
  jumpForce: -11,
  gravity: 0.55,
  maxFall: 12,

  // Присед (для side-scroll)
  duckH: 20,           // уменьшенная высота при приседе
  normalH: 36,
};

function jump() {
  if (!RUNNER.grounded) return;
  RUNNER.vy = RUNNER.jumpForce;
  RUNNER.grounded = false;
  playSound('jump');
  // Частицы пыли
  spawnDust(RUNNER.x, GROUND_Y, 5);
}

function duck(active) {
  RUNNER.ducking = active;
  RUNNER.h = active ? RUNNER.duckH : RUNNER.normalH;
  if (active) RUNNER.y = GROUND_Y - RUNNER.duckH;
}
```

## Визуальные стили для раннера

| Стиль | Земля | Небо/фон | Персонаж | Препятствия |
|-------|-------|----------|----------|-------------|
| **Пустыня/дино** | Песочная линия | Белый/голубой, облака | Простой силуэт | Кактусы, камни |
| **Лесной** | Зелёная трава | Небо + деревья параллакс | Животное | Пни, ежи, камни |
| **Городской** | Асфальт серый | Здания на фоне | Бегун | Урны, барьеры, машины |
| **Космический** | Платформы в пустоте | Звёзды + планеты | Астронавт | Метеориты, лазеры |
| **Геометрический** | Линия | Фон с паттерном | Квадрат/треугольник | Шипы, блоки |
| **Закатный силуэт** | Тёмная линия | Оранжевый градиент | Чёрный силуэт | Тёмные формы |

По дефолту — **пустыня** или **лесной**. Светлые стили лучше читаются для раннера (нужна мгновенная видимость препятствий).

## Параллакс — обязателен для раннера!

Раннер без параллакса выглядит плоско. Минимум 3 слоя:

```javascript
const LAYERS = [
  { elements: [], speed: 0.2, color: '#cde4f7' },  // дальний (облака/горы)
  { elements: [], speed: 0.5, color: '#8cb4d4' },  // средний (деревья/здания)
  { elements: [], speed: 1.0, color: '#555' },      // ближний (земля + декор)
];

// Каждый элемент слоя:
// { x, y, shape, color, w, h }
// Двигается со скоростью: GAME.speed * layer.speed
// При уходе за левый край — респавн справа
```

## Спецэффекты раннера

**Бег:**
- Частицы пыли из-под ног каждые 8-10 кадров
- Ноги "мелькают" (простая анимация 2-3 кадра)

**Прыжок:**
- Squash при отрыве, stretch в воздухе
- Пыль при приземлении
- Звук (sine sweep up)

**Нарастание скорости:**
- Фон слегка blur при высокой скорости (trail эффект)
- Speed lines — горизонтальные полоски при скорости > 8
- Числа расстояния мелькают быстрее

**Подбор монеты/бонуса:**
- Монета "притягивается" к персонажу за 5 кадров
- Частицы золотые, звук "bling"

**Смерть:**
- Slow-mo на 15 кадров (dt *= 0.2)
- Screen shake 8px
- Персонаж отлетает назад с вращением
- Крупные частицы
- Fade → Game Over экран

**Near miss (проехал впритирку):**
- "+CLOSE!" текст всплывает
- Бонусные очки
- Короткий звуковой акцент

## Управление — МИНИМАЛЬНОЕ

- **Пробел / клик / тап** — прыжок
- **Стрелка вниз / S / свайп вниз** — присед (для side-scroll)
- **Стрелки лево-право** — смена полосы (для lane runner)

Чем меньше кнопок — тем лучше. В идеале **одна кнопка**.

---

## Твисты

1. **Двойной прыжок** — второй прыжок в воздухе
2. **Гравитация** — flip гравитации по клику (пол ↔ потолок)
3. **Замедление** — одна "порция" слоу-мо за забег
4. **Трансформация** — на земле бежишь, в воздухе летишь (другая механика)
5. **Разрушение** — можно разбивать некоторые препятствия на бегу (рывком)
6. **Day/night** — каждые 500м смена дня/ночи, ночью видимость ограничена
7. **Ритм** — препятствия в такт "музыке" (тональный паттерн из синтеза)
