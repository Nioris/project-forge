# Puzzle Prototype

Скил для создания 2D-головоломок. Головоломка — жанр, где кайф в моменте "ага, понял!". Каждый ход должен быть осмысленным, а обратная связь — мгновенной и сочной.

## R1 40%

Не пиши генератор 1000 уровней. Прототип = 1 понятная механика, 5-8 хардкоженных уровней/ситуаций, красивая анимация взаимодействий.

## Core: Сетка и анимации

Большинство головоломок живут на сетке. Вот базовая реализация:

```javascript
const GRID = {
  cols: 6,
  rows: 6,
  cellSize: 64,
  padding: 4,
  offsetX: 0, // вычислить для центрирования
  offsetY: 0,
};
GRID.offsetX = (canvasWidth - GRID.cols * GRID.cellSize) / 2;
GRID.offsetY = (canvasHeight - GRID.rows * GRID.cellSize) / 2;

// Координаты клетки → пиксели
function cellToPixel(col, row) {
  return {
    x: GRID.offsetX + col * GRID.cellSize + GRID.cellSize / 2,
    y: GRID.offsetY + row * GRID.cellSize + GRID.cellSize / 2,
  };
}

// Пиксели → клетка
function pixelToCell(px, py) {
  const col = Math.floor((px - GRID.offsetX) / GRID.cellSize);
  const row = Math.floor((py - GRID.offsetY) / GRID.cellSize);
  return { col, row };
}
```

**КРИТИЧНО: анимации между состояниями.** Головоломка без анимаций = таблица Excel. Каждое изменение сетки должно быть анимировано:

```javascript
class AnimatedCell {
  constructor(col, row, type) {
    this.col = col;
    this.row = row;
    this.type = type;
    // Анимация
    this.displayX = cellToPixel(col, row).x;
    this.displayY = cellToPixel(col, row).y;
    this.targetX = this.displayX;
    this.targetY = this.displayY;
    this.scale = 1;
    this.targetScale = 1;
    this.alpha = 1;
  }
  moveTo(newCol, newRow) {
    this.col = newCol;
    this.row = newRow;
    const target = cellToPixel(newCol, newRow);
    this.targetX = target.x;
    this.targetY = target.y;
  }
  update() {
    // Плавное движение
    this.displayX += (this.targetX - this.displayX) * 0.2;
    this.displayY += (this.targetY - this.displayY) * 0.2;
    this.scale += (this.targetScale - this.scale) * 0.2;
  }
}
```

## Визуальные стили для головоломки

Головоломки выигрывают от ЧИСТЫХ, ЧИТАЕМЫХ стилей. Не перегружай:

| Стиль | Фон | Элементы | Когда |
|-------|-----|----------|-------|
| **Минималистичный** | Белый/светло-серый | Цветные круги/квадраты с тенями | По дефолту |
| **Бумажный** | Крафтовый бежевый | "Нарисованные" элементы | Для уютных игр |
| **Стеклянный** | Градиент синий/серый | Полупрозрачные блоки с бликами | Для элегантных паззлов |
| **Пиксель** | Однотонный | 8-bit иконки | Для ретро |
| **Природа** | Зелёный/деревянный | Камни, листья, цветы | Для тематических |
| **Геометрический** | Чёрный или белый | Чистые формы, контрастные цвета | Для абстрактных |

НЕ НЕОН. Головоломке нужна читаемость, а не glow.

## Обратная связь — это ВСЁ

В головоломке нет экшена, поэтому feedback при каждом действии = весь juice:

**При успешном ходе:**
- Элементы плавно скользят на новые позиции (ease-out)
- Лёгкий звук "клик" (sine 400→600Hz, 0.05с)
- Элемент слегка "подпрыгивает" (scale 1→1.15→1)

**При совпадении / решении:**
- Совпавшие элементы увеличиваются, затем "лопаются" (scale 1→1.3→0)
- Частицы цвета элемента (10-15 штук)
- Звук "pop" / "ding" (sine sweep вверх)
- Числа очков всплывают и исчезают (+100, +200...)
- Комбо-множитель показывается крупным текстом

**При неправильном ходе:**
- Элемент трясётся (±3px на 5 кадров)
- Низкий звук "бзз" (square 200→100Hz, 0.1с)
- Элемент возвращается назад

**При решении уровня:**
- ВСЕ элементы "взрываются" каскадом (с задержкой)
- Фейерверк из частиц
- Крупный текст "LEVEL COMPLETE" с анимацией масштаба
- Звук фанфар (аккорд из 3 нот: C-E-G)

## Звуки головоломки

Мягче и приятнее чем в шутере:
```
move:       sine 400→500Hz, 0.05с, gain 0.15 (тихий, частый)
match:      sine 600→900Hz, 0.1с, gain 0.2
combo:      sine chord: базовая нота * 1, 1.25, 1.5 (мажорный аккорд)
error:      square 200→100Hz, 0.1с, gain 0.15
levelup:    sine sweep 400→800→1200Hz, 0.3с
```

**Музыкальные комбо:** при последовательных совпадениях каждый звук на полтона выше предыдущего. Создаёт мелодию из геймплея.

## Управление

- **Мышь / тач** — основное! Клик, драг, свайп
- **Клавиатура** — стрелки + Enter для sokoban/sliding, WASD альтернативно
- **Undo** — Z или Ctrl+Z. ОБЯЗАТЕЛЬНО для sokoban/логических

---

## Твисты

1. **Гравитация** — после каждого хода элементы "падают" вниз
2. **Таймер** — ограничение по времени, давление
3. **Ограниченные ходы** — "реши за N ходов"
4. **Цепные реакции** — одно совпадение вызывает каскад
5. **Двойная сетка** — два поля, действия на одном влияют на другое
6. **Мутации** — элементы меняют тип каждые N ходов
7. **Слияние** — два одинаковых = один улучшенный (2048-стиль)
