# Simulation Prototype

Скил для создания 2D-симуляторов. Сим — жанр про уютный рост. Начинаешь с малого, постепенно расширяешь, оптимизируешь, и наблюдаешь как всё крутится.

## R1 40%

Прототип = 1 локация (ферма/кафе/магазин), 5-8 объектов для размещения, клиенты/время, простая экономика.

---

## Core: Экономический цикл

```javascript
// Универсальный цикл для любого сима
// Ресурс → Производство → Продукт → Продажа → Деньги → Расширение

const state = {
  money: 100,
  day: 1,
  time: 0,        // 0-100 (день)
  speed: 1,       // x1, x2, x3
  objects: [],     // размещённые объекты (грядки, столики, прилавки)
  workers: [],
  customers: [],
  resources: {},
};

// Объекты производят ресурсы со временем
class ProductionObject {
  constructor(type, col, row) {
    this.type = type;
    this.col = col; this.row = row;
    this.progress = 0;
    this.ready = false;
    this.def = CONFIG.objects[type];
  }
  update(dt) {
    if (!this.ready) {
      this.progress += dt * this.def.speed;
      if (this.progress >= this.def.produceTime) {
        this.ready = true;
      }
    }
  }
  harvest() {
    if (!this.ready) return null;
    this.ready = false;
    this.progress = 0;
    return { item: this.def.produces, amount: this.def.yield };
  }
}
```

## Поджанры

| Тип | Объекты | Клиенты | Цикл |
|-----|---------|---------|------|
| **Ферма** | Грядки, деревья, животные | Нет (продажа на рынке) | Сажай → расти → собирай → продавай |
| **Кафе/Ресторан** | Столики, кухня, касса | Приходят, заказывают, ждут | Готовь → подавай → получай чаевые |
| **Магазин** | Полки, склад, касса | Берут товар, платят | Закупай → выставляй → продавай |
| **Город** | Дома, дороги, заводы | Жители | Строй → заселяй → налоги → расширяй |

## Визуальные стили

| Стиль | Палитра | Когда |
|-------|---------|-------|
| **Пиксельный уютный** | Тёплые зелёные, коричневые | Ферма |
| **Мультяшный яркий** | Пастельные яркие | Кафе, магазин |
| **Изометрический** | Землистые + акцент | Город |
| **Минималистичный** | Чистые цвета | Абстрактный тайкун |

**Главное в симе — УЮТНАЯ атмосфера.** Мягкие цвета, плавные анимации, приятные звуки.

## Спецэффекты сима

- Монетки вылетают при продаже (+$)
- Растения плавно растут (scale анимация по этапам)
- Клиенты ходят по путям (не телепортируются)
- Смайлики/сердечки над довольными клиентами
- Прогресс-бары на объектах (сколько до готовности)
- День/ночь цикл (фон плавно меняет оттенок)

## Звуки
```
coin:       sine 800→1200Hz, 0.08с (приятный bling)
plant:      sine 200→300Hz, 0.1с (мягкий)
harvest:    sine chord 500-700-900Hz, 0.15с
customer:   sine 400→500Hz, 0.05с (дзинь двери)
upgrade:    sine sweep 300→800Hz, 0.2с
negative:   square 200→100Hz, 0.1с
```

## Управление

- **Мобилка** — тап = клик, pinch = zoom (опционально)
