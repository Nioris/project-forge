# Platformer Prototype

Скил для создания 2D-платформеров. Платформер — жанр, где core feel определяется физикой прыжка. Плохой прыжок = мёртвая игра, отличный прыжок = хочется прыгать даже без цели.

## R1 40% — думай быстро, делай красиво

Не проектируй редактор уровней и систему тайлов. Прототип платформера = 1 экран с платформами, хорошая физика, 1 фишка. Уровни можно захардкодить массивом.

---

## Core: Физика прыжка

Это САМОЕ важное. 80% ощущений от платформера — в прыжке. Вот эталонная реализация:

```javascript
const PHYSICS = {
  gravity: 0.6,           // притяжение за кадр
  jumpForce: -12,         // начальная скорость прыжка (отрицательная = вверх)
  jumpCutMultiplier: 0.4, // при отпускании кнопки — гасим скорость (variable jump height)
  maxFallSpeed: 10,       // терминальная скорость падения
  moveSpeed: 4,           // скорость бега
  acceleration: 0.8,      // ускорение (не мгновенная скорость!)
  friction: 0.85,         // трение при остановке
  coyoteTime: 6,          // кадров после схода с платформы, когда ещё можно прыгнуть
  jumpBuffer: 8,          // кадров до приземления, когда нажатие запоминается
  airControl: 0.6,        // множитель управления в воздухе (< 1 = менее отзывчиво)
};
```

**Обязательные механики прыжка:**
- **Variable jump height** — короткое нажатие = низкий прыжок, долгое = высокий. При отпускании `if (vy < 0) vy *= jumpCutMultiplier`
- **Coyote time** — после схода с края платформы ещё 4-6 кадров можно нажать прыжок
- **Jump buffering** — если нажал прыжок за 6-8 кадров до приземления, прыжок сработает при касании
- **Ускорение + трение** — персонаж не мгновенно набирает скорость и не мгновенно стоит. `vx = vx * friction + input * acceleration`

**Коллизия с платформами:**
```javascript
// Простой AABB — достаточно для прототипа
function checkCollision(player, platforms) {
  player.grounded = false;
  for (const p of platforms) {
    if (player.x + player.w > p.x && player.x < p.x + p.w &&
        player.y + player.h > p.y && player.y < p.y + p.h) {
      // Сверху — приземление
      if (player.vy > 0 && player.y + player.h - player.vy <= p.y) {
        player.y = p.y - player.h;
        player.vy = 0;
        player.grounded = true;
      }
    }
  }
}
```

## Визуальные стили для платформера

Выбирай один, НЕ ВСЕГДА НЕОН:

| Стиль | Фон | Персонаж | Платформы | Когда |
|-------|-----|----------|-----------|-------|
| **Пиксель-арт** | Небо с градиентом, облака | Квадратный спрайт 16x16 | Блоки с текстурой | По дефолту — самый "платформерный" |
| **Бумажный мир** | Бежевый `#f5e6c8` с текстурой | Нарисованный "от руки" | Неровные рваные формы | Для уютных/инди игр |
| **Природа** | Градиент неба + деревья на фоне | Животное / человечек | Земля, трава, камни | Когда просят "лес" / "природу" |
| **Геометрия** | Белый/серый | Квадрат или круг | Чистые прямоугольники | Для puzzle-platformer |
| **Закат/силуэт** | Оранжево-розовый градиент | Тёмный силуэт | Тёмные силуэты | Для атмосферных игр (Limbo-стиль) |
| **Неон** | Тёмный | Светящийся контур | Светящиеся линии | ТОЛЬКО если просят космос/киберпанк |

## Рисование персонажа (без спрайтов)

Не грузи картинки. Рисуй программно и это будет выглядеть стильно:

```javascript
function drawPlayer(ctx, player, time) {
  ctx.save();
  ctx.translate(player.x + player.w/2, player.y + player.h/2);

  // Squash & stretch — ОБЯЗАТЕЛЬНО
  let scaleX = 1, scaleY = 1;
  if (!player.grounded) {
    if (player.vy < -2) { scaleX = 0.85; scaleY = 1.2; }  // взлёт — вытягивается
    if (player.vy > 2)  { scaleX = 1.15; scaleY = 0.85; } // падение — сплющивается
  }
  // Приземление — сквош на пару кадров
  if (player.landTimer > 0) { scaleX = 1.3; scaleY = 0.7; player.landTimer--; }

  ctx.scale(scaleX * player.facing, scaleY); // facing = 1 или -1 для разворота

  // Тело
  ctx.fillStyle = player.color;
  ctx.fillRect(-player.w/2, -player.h/2, player.w, player.h);

  // Глаза (дают "характер" за 4 строки кода)
  ctx.fillStyle = '#fff';
  ctx.fillRect(player.facing > 0 ? 2 : -8, -player.h/4, 5, 5);
  ctx.fillStyle = '#111';
  ctx.fillRect(player.facing > 0 ? 4 : -6, -player.h/4 + 1, 2, 2);

  ctx.restore();
}
```

**Squash & stretch** — главная анимация платформера. Персонаж вытягивается при прыжке вверх, сплющивается при приземлении. Без этого прыжки будут "мёртвые".

## Спецэффекты для платформера

**При приземлении:**
- 5-8 частиц пыли в стороны (цвет платформы)
- Screen shake 2px на 3 кадра
- Звук "приземление" (низкий thud)

**При прыжке:**
- 3-4 частицы пыли вниз от ног
- Squash-анимация на 3 кадра
- Звук "прыжок" (sine sweep вверх 200→600Hz)

**При смерти/падении:**
- Взрыв из 20 частиц цвета персонажа
- Screen shake 5px
- Fade to black, респаун

**Фоновые:**
- Облака / листья / снежинки плавно двигаются на заднем плане
- Параллакс: ближний слой быстрее дальнего

## Твисты для уникальности

Каждый платформер должен иметь ОДНУ уникальную механику. Выбери одну:

1. **Переключение гравитации** — прыжок вверх ИЛИ вниз (flip)
2. **Вращение мира** — уровень поворачивается на 90° по нажатию
3. **Двойная жизнь** — два персонажа управляются зеркально
4. **Стены = пол** — можно бегать по стенам/потолку
5. **Размер меняется** — маленький проходит в щели, большой высоко прыгает
6. **Время** — замедление / перемотка по кнопке
7. **Строитель** — игрок ставит платформы кликом мыши
8. **Dash** — рывок в направлении + неуязвимость на мгновение

## Генерация уровней (простой способ)

Для прототипа — массив объектов:
```javascript
const LEVELS = [
  { platforms: [
    { x: 0, y: 380, w: 800, h: 20 },    // пол
    { x: 200, y: 300, w: 80, h: 15 },    // платформа
    { x: 350, y: 230, w: 80, h: 15 },
    { x: 500, y: 160, w: 80, h: 15 },
    { x: 650, y: 100, w: 60, h: 15 },    // финиш
  ], spawn: { x: 50, y: 340 }, goal: { x: 660, y: 80 } }
];
```

Или процедурная генерация: цепочка платформ с рандомным смещением, каждая достижима с учётом jumpForce и moveSpeed.

jump:     sine 200→600Hz за 0.12с, gain 0.2

death:    noise burst 0.3с + sine 400→100Hz

## Управление

- **Стрелки / WASD** — движение
- **Пробел / W / стрелка вверх** — прыжок (все три варианта!)
- **Мышь / тач** — тап слева/справа для движения, тап на персонаже для прыжка, или виртуальные кнопки внизу экрана
