# Idle / Clicker Prototype

Скил для создания Idle/Clicker игр. Кликер — жанр, где кайф в числах, которые растут, и ощущении прогресса. Каждый клик должен быть СОЧНЫМ, каждый апгрейд — менять ощущение игры.

## R1 40%

Не делай 50 апгрейдов и систему престижа. Прототип = 1 основной ресурс, 5-8 апгрейдов, автокликер, визуально сочный клик. Залипательность важнее глубины.

## Core: Экономика больших чисел

```javascript
// Форматирование больших чисел — ОБЯЗАТЕЛЬНО
function formatNumber(n) {
  if (n < 1000) return Math.floor(n).toString();
  const suffixes = ['', 'K', 'M', 'B', 'T', 'Qa', 'Qi', 'Sx', 'Sp', 'Oc'];
  const tier = Math.floor(Math.log10(n) / 3);
  if (tier >= suffixes.length) return n.toExponential(2);
  const scaled = n / Math.pow(10, tier * 3);
  return scaled.toFixed(1) + suffixes[tier];
}

// Основная экономика
const state = {
  currency: 0,           // основной ресурс
  clickPower: 1,         // за клик
  autoPerSecond: 0,      // пассивный доход
  totalClicks: 0,
  totalEarned: 0,
  upgrades: {},          // купленные апгрейды
};

// Стоимость апгрейда растёт экспоненциально
function upgradeCost(base, level) {
  return Math.floor(base * Math.pow(1.15, level));
}
```

**Золотое правило кликера:** следующий апгрейд стоит ~10-30 секунд текущего дохода. Если дешевле — нет ощущения прогресса. Дороже — скучно ждать.

## Визуальные стили для кликера

Кликер = UI-heavy. Тут стиль определяется не Canvas, а оформлением панелей и кнопок.

| Стиль | Фон | Кнопка клика | Апгрейды | Когда |
|-------|-----|-------------|----------|-------|
| **Тёплый/уютный** | Кремовый `#fef9ef` | Круглая, мягкие тени | Карточки с иконками | По дефолту |
| **Ретро-пиксель** | Тёмный | Пиксельная кнопка | Пиксельные панели | Для ностальгии |
| **Стимпанк** | Коричнево-бронзовый | Шестерёнка | Механизмы с рычагами | Для "фабрики" |
| **Космический** | Тёмно-синий со звёздами | Планета / звезда | Технологии | Для sci-fi |
| **Кондитерский** | Розово-пастельный | Печенье / кекс | Сладости | Cookie Clicker стиль |
| **Минимал** | Белый | Одна большая цифра | Текстовый список | Для чистоты |

**Главное правило:** центральный объект (то, что кликают) должен быть БОЛЬШИМ и СОЧНЫМ. Минимум 30% экрана.

## Juice клика — самое важное

Каждый клик = мини-праздник. Вот что должно происходить:

```javascript
function handleClick(x, y) {
  // 1. Числа
  state.currency += state.clickPower;
  state.totalClicks++;

  // 2. Визуальный feedback
  // Всплывающее число
  floatingTexts.push({
    x: x + (Math.random() - 0.5) * 30,
    y: y,
    text: '+' + formatNumber(state.clickPower),
    vy: -2,
    life: 1.0,
    color: '#ffcc00',
    size: 16 + Math.min(state.clickPower, 30), // размер растёт с силой клика
  });

  // Частицы из точки клика
  for (let i = 0; i < 5 + Math.min(state.clickPower, 15); i++) {
    particles.push({
      x, y,
      vx: (Math.random() - 0.5) * 6,
      vy: (Math.random() - 0.5) * 6 - 2,
      life: 0.6 + Math.random() * 0.3,
      color: PARTICLE_COLORS[Math.floor(Math.random() * PARTICLE_COLORS.length)],
      size: 3 + Math.random() * 3,
    });
  }

  // Пульсация кнопки
  buttonScale = 0.92; // сжатие, затем обратно через lerp

  // 3. Звук
  playClickSound();

  // 4. Каждые 100 кликов — мини-бонус / визуальный праздник
  if (state.totalClicks % 100 === 0) {
    spawnFireworks(x, y);
    playAchievementSound();
  }
}
```

**Пульсация центрального объекта:**
```javascript
// В render loop:
buttonScale += (1.0 - buttonScale) * 0.15; // плавно возвращается
ctx.save();
ctx.translate(centerX, centerY);
ctx.scale(buttonScale, buttonScale);
// рисуем кнопку
ctx.restore();
```

## Счётчик ресурса — красиво!

Число не должно просто меняться. Оно должно "катиться":

```javascript
let displayedCurrency = 0;

function updateDisplay() {
  // Число плавно догоняет реальное
  const diff = state.currency - displayedCurrency;
  displayedCurrency += diff * 0.1;

  // Рисуем крупно, по центру сверху
  ctx.font = 'bold 48px monospace';
  ctx.textAlign = 'center';
  ctx.fillStyle = '#333';
  ctx.fillText(formatNumber(displayedCurrency), canvasWidth/2, 60);

  // Маленький текст "/сек"
  ctx.font = '16px sans-serif';
  ctx.fillStyle = '#888';
  ctx.fillText(formatNumber(state.autoPerSecond) + ' / сек', canvasWidth/2, 85);
}
```

## Звуки кликера

Мягкие, приятные, не утомляют при спаме:
```
click:       sine 600→800Hz, 0.03с, gain 0.1 (ТИХИЙ! будет 100 раз в минуту)
buy:         sine 400→600→800Hz (аккорд), 0.15с, gain 0.15
cantBuy:     square 200Hz, 0.05с, gain 0.1
milestone:   sine sweep 400→800→1200Hz, 0.3с, gain 0.2
autoTick:    sine 500Hz, 0.01с, gain 0.03 (еле слышный тик для авто-дохода)
```

**Важно:** звук клика должен быть ОЧЕНЬ коротким и тихим, потому что игрок кликает быстро. Раздражающий звук клика = игра выключена.

## Управление

- **Клик / тап** — основное действие
- **Кнопки апгрейдов** — клик для покупки
- **Hover** — показать стоимость и эффект
- **Горячие клавиши** — 1-5 для быстрой покупки апгрейдов (опционально)

---

## Твисты

1. **Мини-игра** — каждые 30 секунд появляется "золотой объект" — кликни быстро для бонуса
2. **Комбо** — быстрые клики дают множитель (x2, x3...) который затухает
3. **Выбор пути** — после определённого количества ресурса: "инвестируй в X или Y?"
4. **Мутация** — центральный объект визуально меняется с прогрессом
5. **Мини-боссы** — каждые N единиц появляется "босс" с HP-баром, кликай быстро!
6. **Коллекция** — открываешь новые типы "добычи" по мере прогресса
