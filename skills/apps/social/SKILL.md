# Social App Prototype

Social apps: instant participation, visual feedback, shareability.

## Sub-types

| Type | Mechanic | Key UI |
|------|----------|--------|
| Poll/Vote | Pick option | Animated bar chart |
| Reaction board | Drop emojis | Canvas with floating reactions |
| Wheel spinner | Spin to pick | Animated wheel, confetti |
| Team picker | Random groups | Shuffle animation |
| Icebreaker | Random questions | Card flip |
| Shared list | Collaborative | Add items, vote |

## Visual Style
- Rose: `#E84393, #FD79A8, #FAFBFC, #2D3436, #FFEEF5`
- OR Sunset: `#E17055, #FFEAA7, #FAFBFC, #2D3436, #FFF5E6`
- Emoji heavy, rounded everything
- Confetti animations
- Big tap targets
