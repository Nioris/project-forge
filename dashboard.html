Экономия лимитов

Используй Shift+Tab для режима планирования перед большими задачами. Claude продумает план без лишних токенов.
Команда /compact сжимает историю когда контекст раздулся. Экономит промпты.
Для рутинных задач переключи модель: /model и выбери Sonnet (дешевле). Opus оставь для архитектуры.
Не пиши 10 задач в одном промпте. Лучше 3 конкретных чем 10 расплывчатых.
Создай .claudeignore в проекте: туда node_modules/, dist/, *.lock - Claude не будет их сканировать.

Ошибки при сборке

Claude использует версии SDK из обучающих данных (устаревшие!). Если ошибка — НЕ давай ему городить костыли. Скажи: "Посмотри в интернете актуальную версию этого SDK и обнови"
Перед сборкой полезно сказать: "Проверь через веб-поиск актуальные версии Capacitor, Gradle Plugin и всех SDK"

Формулировка промптов

Длинный промпт? Нажми Ctrl+G в терминале — откроется Блокнот. Вставь текст любой длины, сохрани (Ctrl+S), закрой. Текст отправится в Claude автоматически. Лучший способ!
Промпт ОДНОЙ СТРОКОЙ. Claude Code плохо принимает многострочные вставки.
Если длинный промпт - создай файл prompt.md в проекте и напиши Claude: "Прочитай prompt.md и выполни"
Всегда пиши на русском - иначе Claude переключится на английский.
Используй /advisor - опиши задачу своими словами, получи готовый промпт.
Не пиши "сделай хорошо". Пиши конкретно: "исправь утечку watchPosition в высотомере, добавь clearWatch при уходе с таба".

Аудит и отладка

Перед сборкой всегда проси аудит: "Сделай полный аудит на ошибки и фейковый функционал, формат: КРИТИЧНО/ВАЖНО/МЕЛОЧЬ, не исправляй - только отчёт"
После аудита: "Исправь все критичные и важные проблемы из аудита" - он помнит список.
Если баг от пользователя: "Пользователь пишет: [точная цитата]. Найди причину и исправь."
Если модератор отклонил: "Модерация отклонила. Причина: [точная цитата]. Исправь."

Параллельная работа

Пока Claude думает в одном терминале (2-10 мин) - переключись на другой проект.
Открытый терминал в простое = 0 токенов. Можно держать 10 вкладок.
Все терминалы едят из одного пула лимитов. На Pro хватит на 1-2 активных, на Max 20x на 5-8.

Стандартная иконка Capacitor — Claude забывает заменить. Проверь mipmap-* папки!
Устаревшие SDK — Claude использует версии из памяти (2024). Если ошибка при сборке — пусть проверит актуальную версию через поиск, а не городит костыли!

Удалил папку проекта — не создаётся заново

Ошибка: "A branch named 'project/xxx' already exists" — ветка осталась в git
📋 Починить: очистить мёртвую ветку (замени ИМЯ_ПРОЕКТА)
После этого создавай заново: ./new-project.bat имя --type game

Hook error: JSON validation failed / Bash hook error

В актуальном Forge Windows hooks запускаются прямыми Node launchers. Не удаляй hooks: сначала выполни node scripts/check-codex-compat.mjs, затем ./sync.bat и перезапусти Codex-сессию.
📋 Синхронизировать managed Claude+Codex runtime

Ошибка сборки — устаревший SDK

Claude использует версии из памяти (2024). НЕ давай ему городить костыли!
📋 Скажи: обнови SDK

PowerShell: && не работает

PowerShell: subscription-кнопки Claude/Codex остаются как раньше. API-кнопки и GigaChat идут через scripts/forge-agent.mjs. Ключи лежат вне проектов в forge-data/secrets/; GigaSearch key опционален, пока используется no-key fallback. GigaCode CLI необязателен.

Многострочный текст не вставляется в терминал

Нажми Ctrl+G — откроется Блокнот. Вставь любой текст, сохрани, закрой. Отправится автоматически.

Скилы не обновились в проектах

📋 Запусти sync.bat — синхронизирует управляемый Claude+Codex runtime во все проекты и удалит только устаревшие Forge-managed файлы (v4.3.2+)
📋 Или sync.bat --dry — предпросмотр что будет скопировано

ANDROID_HOME не найден

📋 Установить ANDROID_HOME (перезапусти терминал после)

Скажи: "Замени стандартную иконку Capacitor на мою. Файл: [путь]. Сгенерируй все размеры для mipmap."
