# YG Screenshot — Chrome Extension

Скриншоты HTML5-игр для стора Яндекс Игр в точном разрешении.

## Установка
1. Chrome → `chrome://extensions`
2. Включить "Режим разработчика"
3. "Загрузить распакованное расширение" → выбрать эту папку

## Попап (клик по иконке)

### Пресеты разрешений
- **📺 PC** — 1920×1080
- **📱 Mobile** — 1080×1920
- **📐 Current** — текущий размер окна (as-is)
- **⬜ Square** — 1080×1080

### Кастомный размер
Поля ширина × высота + кнопка 📸

### Смена языка
Сетка из 13 кнопок: RU EN ES TR PT AR ID FR JA IT DE HI ZH
Нажми на язык — игра переключится.

### Скриншоты всех языков
Кнопка "🌐 Скриншоты всех 13 языков" — автоматически:
1. Переключает язык
2. Ждёт рендер
3. Делает скриншот в выбранном разрешении
4. Повторяет для каждого из 13 языков
5. Возвращает на RU

## Горячие клавиши
- **Alt+J** — скриншот PC (1920×1080)
- **Alt+K** — скриншот Mobile (1080×1920)
- **Alt+H** — скриншот Current (as-is)

## Куда сохраняются
`Downloads/screenshots/<GameTitle>/<preset>_<lang>_<WxH>_<timestamp>.png`

## Как работает
- Использует Chrome DevTools Protocol (CDP) для точной эмуляции viewport
- Автоматически прячет чит-панель, дебаг-оверлеи, notify тосты
- Совместим с любой игрой, использующей `_lang` + `applyStaticLang()`
- Для смены языка нужен стандартный cheats.js (P=пауза, L=язык) или расширение

## Workflow для скриншотов стора
1. Открой маркетинговый билд игры
2. Ctrl+Shift+9 → чит-панель → настрой игровое состояние
3. P → тихая пауза (без оверлея)
4. Открой расширение → выбери язык → нажми PC/Mobile/Square
5. Или "Все 13 языков" для пакетных скриншотов
