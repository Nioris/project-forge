# Протокол двойной верификации перед модерацией

> **КРИТИЧНО:** Модерация Yandex Games = 3-5 рабочих дней.
> Отказ = следующая попытка через ~неделю.
> Каждый отказ — потерянное время и деньги. Проверять ТЩАТЕЛЬНО.

## Типичные причины отказа (из документации Yandex)

1. Интерфейс не переведён на все заявленные языки
2. Некорректный показ рекламы (во время геймплея, без паузы)
3. Технические ошибки (крэши, зависания, ошибки в консоли)
4. Название в игре не совпадает с названием в драфте
5. Возрастной рейтинг не соответствует контенту
6. Обрезанные элементы UI на мобильных
7. Игра — копия другой игры из каталога
8. `LoadingAPI.ready()` не вызывается
9. Звук продолжает играть при сворачивании
10. Покупки не обрабатываются корректно (нет consumePurchase)

## ПРОХОД 1: Техническая проверка (код-ревью)

### 1.1 SDK подключение
```
Действие: Открыть index.html, проверить наличие:
```
- [ ] `<script src="/sdk.js"></script>` в `<head>`
- [ ] Скрипт обёртки подключён
- [ ] Нет других SDK/рекламных скриптов (сторонних)

### 1.2 Инициализация
```
Действие: Grep по *.js файлам на: YaGames.init, LoadingAPI, GameplayAPI
```
- [ ] `YaGames.init()` вызывается 1 раз при старте
- [ ] `LoadingAPI.ready()` вызывается когда игра готова (используется `?.`)
- [ ] `GameplayAPI.start()` вызывается при начале геймплея (используется `?.`)
- [ ] `GameplayAPI.stop()` вызывается при остановке геймплея (используется `?.`)
- [ ] `start()` и `stop()` вызываются парами (каждый start имеет stop и наоборот)

### 1.3 Реклама
```
Действие: Grep по *.js на: showFullscreenAdv, showRewardedVideo, showBannerAdv
```
- [ ] `showFullscreenAdv` вызывается ТОЛЬКО в pause points (не в game loop)
- [ ] Колбэк `onOpen` — ставит на паузу + глушит звук
- [ ] Колбэк `onClose` — возобновляет + включает звук
- [ ] `showRewardedVideo` — привязан к кнопке (onclick), не автоматический
- [ ] `onRewarded` — содержит логику начисления
- [ ] Нет `setInterval`/`setTimeout` с рекламой (это фрод!)
- [ ] Нет сторонних рекламных SDK

### 1.4 Звук
```
Действие: Grep по *.js на: game_api_pause, game_api_resume, visibilitychange, blur, focus
```
- [ ] Обработчик `game_api_pause` — глушит звук
- [ ] Обработчик `game_api_resume` — возобновляет звук
- [ ] Или: события паузы обрабатываются через обёртку SDK
- [ ] `visibilitychange` или `blur/focus` — глушит звук при сворачивании

### 1.5 Сохранения
```
Действие: Grep по *.js на: localStorage, sessionStorage
```
- [ ] Нет прямых вызовов `localStorage` (заменены на `player.setData/getData`)
- [ ] Или: используется `ysdk.getStorage()` как замена
- [ ] `setData` вызывается при значимых событиях (конец уровня, покупка, настройки)
- [ ] Данные загружаются при старте (`getData`)

### 1.6 Покупки (если есть) — п. 1.13.1
```
Действие: Grep по *.js на: purchase, consumePurchase, getPurchases
```
- [ ] Правильный порядок: начислить товар → `player.setData()` (сохранить в облако) → `consumePurchase()`
- [ ] `consumePurchase()` вызывается ТОЛЬКО ПОСЛЕ успешного сохранения данных в облако
- [ ] При старте игры ОБЯЗАТЕЛЬНО вызывается `getPurchases()` для незавершённых
- [ ] Каждая незавершённая покупка начисляется → сохраняется → consume'ится
- [ ] Нет синхронного вызова `consumePurchase()` без ожидания `setData()`
- [ ] Цены берутся из `getCatalog()`, не захардкожены
- [ ] Несоблюдение = отключение покупок или снятие с публикации

### 1.7 Локализация
```
Действие: Grep по *.js на: i18n.lang, getLang, хардкод строки
```
- [ ] Язык определяется через `ysdk.environment.i18n.lang`
- [ ] Есть объект/файл переводов минимум на заявленные языки
- [ ] Нет хардкод строк на одном языке в UI (все через систему переводов)
- [ ] Fallback на английский если язык не поддерживается

### 1.8 Файловая система
```
Действие: Запустить scripts/analyze-game.sh
```
- [ ] `index.html` в корне `GameIntegration/`
- [ ] Нет пробелов в именах файлов
- [ ] Нет кириллицы в именах файлов
- [ ] Размер < 100 МБ
- [ ] Нет абсолютных URL на `yandex` серверы

### 1.9 Опасные паттерны
```
Действие: Grep по *.js на потенциальные проблемы
```
- [ ] Нет `alert()`, `confirm()`, `prompt()` (блокируют страницу)
- [ ] Нет `document.write()` (может сломать страницу)
- [ ] Нет незакрытых `TODO`, `FIXME`, `HACK`, `XXX`
- [ ] Нет `debugger` стейтментов
- [ ] Нет `console.error()` в продакшн коде
- [ ] Нет утечек памяти (removeEventListener для каждого addEventListener)
- [ ] Нет бесконечных циклов / рекурсий без выхода

## ПРОХОД 2: Поведенческая проверка (эмуляция пользователя)

### 2.1 Загрузка
- [ ] Игра загружается без ошибок
- [ ] Прогресс загрузки отображается
- [ ] `LoadingAPI.ready()` отправляется (проверить в debug panel)
- [ ] Стартовая реклама Yandex отображается без проблем
- [ ] Звук НЕ играет во время стартовой рекламы

### 2.2 Главное меню
- [ ] Меню отображается корректно
- [ ] Все кнопки работают
- [ ] Язык определён правильно (соответствует настройкам)
- [ ] Переключатель звука работает
- [ ] Нет выхода за пределы экрана

### 2.3 Геймплей
- [ ] `GameplayAPI.start()` вызывается при начале
- [ ] Управление работает (клавиатура + мышь / тач)
- [ ] Нет зависаний при длительной игре
- [ ] Нет ошибок в консоли браузера
- [ ] Счёт считается корректно

### 2.4 Пауза
- [ ] `GameplayAPI.stop()` вызывается
- [ ] Геймплей действительно останавливается
- [ ] Кнопки паузы работают (Resume, Restart, Menu)
- [ ] Возврат из паузы корректен (`GameplayAPI.start()`)

### 2.5 Реклама в игре
- [ ] Interstitial показывается в правильных местах (конец уровня, смерть)
- [ ] Игра на паузе во время рекламы
- [ ] Звук выключен во время рекламы
- [ ] После закрытия: игра возобновляется, звук возвращается
- [ ] Состояние игры сохранено (позиция, очки, уровень)
- [ ] Rewarded Video: кнопка видна и кликабельна
- [ ] Rewarded Video: награда начисляется после просмотра
- [ ] Rewarded Video: можно играть без просмотра (награда = бонус)

### 2.6 Конец игры / уровня
- [ ] Экран конца отображается
- [ ] Результат показан (счёт, рекорд)
- [ ] Кнопки работают (Restart, Menu, Watch Ad)
- [ ] Данные сохранены (рекорд, прогресс)
- [ ] Лидерборд обновлён (если есть)

### 2.7 Сохранения
- [ ] Перезагрузить страницу → данные сохранены
- [ ] Прогресс восстанавливается корректно
- [ ] Настройки звука сохраняются

### 2.8 Покупки (если есть)
- [ ] Каталог отображается с ценами
- [ ] Покупка проходит
- [ ] Товар начисляется
- [ ] Повторный вход → незавершённые покупки обработаны
- [ ] Купленные товары сохраняются между сессиями

### 2.9 Мобильный вид
- [ ] Fullscreen во время геймплея
- [ ] Тач работает точно
- [ ] Поворот экрана — нет искажений
- [ ] Нет скролла страницы при жестах
- [ ] Нет контекстного меню при long-press
- [ ] Клавиатура появляется для полей ввода

### 2.10 Десктоп вид
- [ ] Растягивается до краёв окна
- [ ] Нет контекстного меню на игровой области
- [ ] Клавиатура + мышь работают
- [ ] Ресайз окна — нет искажений

## Шпаргалка: grep-команды для проверки

```bash
# Оставшийся localStorage
grep -rn "localStorage" GameIntegration/ --include="*.js"

# Опасные функции
grep -rn "alert\|confirm\|prompt\|document\.write" GameIntegration/ --include="*.js"

# Незакрытые TODO
grep -rn "TODO\|FIXME\|HACK\|XXX" GameIntegration/ --include="*.js"

# Debugger стейтменты
grep -rn "debugger" GameIntegration/ --include="*.js"

# Проверка SDK вызовов
grep -rn "LoadingAPI\|GameplayAPI\|showFullscreenAdv\|showRewardedVideo" GameIntegration/ --include="*.js"

# Проверка звука при паузе
grep -rn "game_api_pause\|game_api_resume\|visibilitychange" GameIntegration/ --include="*.js"

# Проверка покупок
grep -rn "consumePurchase\|getPurchases\|purchase" GameIntegration/ --include="*.js"

# Пробелы в именах
find GameIntegration/ -name "* *"

# Кириллица в именах
find GameIntegration/ -regex '.*[а-яА-ЯёЁ].*'

# Размер
du -sh GameIntegration/
```
