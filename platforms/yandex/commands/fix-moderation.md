# /fix-moderation — Разбор замечаний модерации

Пользователь вставляет текст замечаний от модерации Яндекс Игр. Задача — разобрать каждое замечание, классифицировать и исправить.

## Шаги

### 1. Парсинг замечаний
Разбить текст на отдельные замечания. Каждое замечание содержит:
- Описание проблемы
- Ссылку на пункт требований (п. X.X.X)
- Ссылки на скриншоты (опционально)

### 2. Классификация каждого замечания

Определить тип для каждого:

**🔧 КОД** — исправить в `GameIntegration/index.html`:
- Контекстное меню / выделение текста
- Пауза при рекламе
- Звук при рекламе
- GameReady API / LoadingAPI
- GameplayAPI start/stop
- Локализация / автоопределение языка
- Размеры текста / UI overlaps на мобильных
- localStorage → SDK сохранения
- Покупки / consumePurchase
- Опасные паттерны (alert, confirm, prompt)

**📋 КОНСОЛЬ** — исправить в панели управления Яндекс Игр:
- Название игры не совпадает → привести к единому
- Возрастной рейтинг → поставить правильный
- Промо-материалы → заменить скриншоты
- Иконка / обложка → загрузить новые
- Описание игры → переписать
- Категория / теги → исправить

### 3. Для каждого замечания типа КОД

1. Найти проблемное место в коде (Grep + Read)
2. Определить что именно не так
3. Исправить (Edit)
4. Проверить что исправление не сломало другой код

### 4. Для каждого замечания типа КОНСОЛЬ

Выдать чёткую инструкцию:
```
📋 КОНСОЛЬ: {описание}
→ Перейти: Яндекс.Игры → Мои игры → {игра} → Черновик
→ Раздел: {какой раздел}
→ Действие: {что изменить}
```

### 5. После всех исправлений

1. Запустить `/verify-yandex` — убедиться что код чист
2. Запустить `/build-release` — собрать новый ZIP

## Карта типичных замечаний

| Пункт | Замечание | Тип | Как исправить |
|-------|-----------|-----|---------------|
| 1.6.2.7 | Контекстное меню / выделение | КОД | `contextmenu` → preventDefault, CSS user-select:none |
| 1.8 | Мелкий текст/иконки | КОД | @media(max-width:768px) увеличить font-size |
| 1.10.3 | UI наложения | КОД | Разнести position:fixed элементы |
| 1.19 | GameReady API | КОД | LoadingAPI.ready() после полной загрузки |
| 2.7 | Возрастной рейтинг | КОНСОЛЬ | Поменять в настройках черновика |
| 2.14 | Автоопределение языка | КОД | ysdk.environment.i18n.lang + detectLang |
| 4.7 | Пауза при рекламе | КОД | onOpen → gs='paused' + AC.suspend() |
| 4.7 | Звук при рекламе | КОД | onOpen → AC.suspend(), onClose → AC.resume() |
| 5.1.1 | Промо-материалы | КОНСОЛЬ | Загрузить скриншоты реального геймплея ≥70% |
| 5.1.3 | Название не совпадает | КОНСОЛЬ | Привести к единому во всех полях |
