# Yandex Games — Чеклист перед модерацией

## SDK Интеграция
- [ ] SDK подключён (`<script src="/sdk.js"></script>`)
- [ ] `YaGames.init()` вызывается при старте
- [ ] `LoadingAPI.ready()` вызывается когда игра готова к взаимодействию
- [ ] `GameplayAPI.start()` вызывается при начале геймплея
- [ ] `GameplayAPI.stop()` вызывается при паузе/конце уровня
- [ ] Используется optional chaining (`?.`) для LoadingAPI и GameplayAPI

## Звук
- [ ] Звук отключается при сворачивании вкладки/окна
- [ ] Звук отключается при показе fullscreen рекламы
- [ ] Звук отключается при показе rewarded video
- [ ] Обрабатываются события `game_api_pause` и `game_api_resume`
- [ ] При стартовой рекламе (автоматической) звук отключён

## Реклама
- [ ] Нет сторонней рекламы (только через SDK)
- [ ] Interstitial показывается только в естественных паузах
- [ ] Interstitial НЕ показывается во время активного геймплея
- [ ] Rewarded Video — только по клику игрока
- [ ] Кнопка RV имеет понятный текст (описание награды)
- [ ] Награда за RV — бонус, не блокирует прогресс
- [ ] Состояние игры сохраняется после возврата из рекламы
- [ ] Ориентация рекламы совпадает с ориентацией игры
- [ ] Игра ставится на паузу при показе рекламы
- [ ] Нет custom RTB баннеров
