# Генерация арт-промтов для Yandex Games

## Назначение
После сборки релизного ZIP генерируются промты для создания визуальных ассетов игры в нейросетях. Промты сохраняются в `Release/` рядом с ZIP-архивом.

## Когда выполняется
**После Фазы 2, параллельно со сборкой релиза (шаг 9).** Результат — файл `Release/<game-name>-art-prompts.md`.

## Целевые нейросети
| Нейросеть | Особенности промтов |
|-----------|-------------------|
| **Midjourney** | Структура: описание, стиль, параметры `--ar`, `--v`, `--style`, `--s`, `--q`. Краткий, через запятые. |
| **GPT Image** (DALL-E) | Развёрнутое описание сцены на английском. Детальное, повествовательное. |
| **Nano Banan 2** | Аналогично GPT Image, но короче. Поддерживает стилевые теги. |

## Какие ассеты генерировать

### Обязательные (для публикации на Yandex Games)
1. **Иконка игры** (512x512) — основная иконка в каталоге
2. **Обложка** (800x470) — баннер/превью игры в каталоге
3. **Промо-баннер** (1920x1080) — для рекомендаций и подборок

### Дополнительные (для маркетинга)
4. **Квадратный промо** (1080x1080) — для соцсетей
5. **Ключевой арт** — центральная иллюстрация игры
6. **Персонажи** — главный герой, боссы, NPC (если есть)
7. **Сцены** — ключевые локации/моменты игры

## Как писать промты

### Принципы
1. **Язык:** только английский
2. **Стиль:** соответствует визуальному стилю игры (pixel art → pixel art промты, 3D → 3D промты)
3. **Консистентность:** все промты в одном стиле, чтобы ассеты выглядели как серия
4. **Специфика:** упоминать конкретные элементы игры (цвета, объекты, персонажей)
5. **Три версии:** для каждого ассета — вариант под каждую нейросеть

### Структура промта

#### Midjourney
```
[subject], [style keywords], [mood/lighting], [composition], --ar [ratio] --v 6.1 --s [stylize] --q 1
```

#### GPT Image
```
[Detailed scene description in 2-3 sentences. Include subject, environment, lighting, mood, art style, color palette, and composition.]
```

#### Nano Banan 2
```
[Concise scene description, 1-2 sentences. Style tag at end.]
```

### Анализ игры для промтов
Перед генерацией промтов проанализировать:
1. **Визуальный стиль** — pixel art, low-poly, cartoon, realistic
2. **Цветовая палитра** — основные цвета из CSS/кода
3. **Ключевые элементы** — главный герой, враги, локации, предметы
4. **Настроение** — весёлое, мрачное, эпичное, уютное
5. **Жанр** — для правильного позиционирования
6. **Уникальные фичи** — что отличает игру, на чём акцент
