# UI/UX Чеклист — Проверка перед модерацией Яндекс Игр

Этот чеклист дополняет `CHECKLIST.md` и фокусируется на **визуальной корректности UI** — основной причине отказов модерации.

---

## 1. Элементы не обрезаются/не выходят за экран (п. 1.10.1)

### Десктоп (1280x800, 1920x1080)
- [ ] Все кнопки полностью видны и кликабельны
- [ ] Текст не выходит за границы контейнеров
- [ ] HUD полностью помещается на экране
- [ ] Попапы/оверлеи не выходят за #game
- [ ] Легенда карты не перекрывает важные элементы

### Мобильный (375x812 iPhone, 390x844, 360x780 Android)
- [ ] HUD компактный, все элементы помещаются
- [ ] Бейджи/статы не обрезаются
- [ ] Нижняя панель кнопок полностью видна
- [ ] Попапы помещаются в экран, не выходят за safe-area
- [ ] Поисковая строка не перекрывается клавиатурой
- [ ] Текст событий скроллится если не помещается
- [ ] Кнопки выбора (choices) не обрезаются

### Планшет (768x1024 iPad)
- [ ] Пропорции корректны, нет растяжения
- [ ] Шрифты читаемы

### Landscape мобильный
- [ ] Игра работает при повороте экрана
- [ ] Элементы не налезают друг на друга

---

## 2. Автоопределение языка (п. 2.14)

- [ ] `ysdk.environment.i18n.lang` читается при инициализации
- [ ] Язык определяется ДО вызова `LoadingAPI.ready()`
- [ ] При смене языка в отладчике SDK — UI полностью на нужном языке
- [ ] Нет хардкод строк на одном языке в HTML
- [ ] `applyStaticLang()` обновляет ВСЕ элементы UI
- [ ] `localizeGameData()` переводит игровые данные
- [ ] Fallback на navigator.language только в dev-режиме
- [ ] console.log показывает `[I18N] SDK ysdk.environment.i18n.lang = ...`

---

## 3. GameReady API (п. 1.19)

- [ ] `LoadingAPI.ready()` вызывается ПОСЛЕ полной загрузки UI
- [ ] Шрифты загружены (`document.fonts.ready`) до ready()
- [ ] Title screen полностью отрисован до ready()
- [ ] В console.log: `[Plat] LoadingAPI.ready() called — game is playable`
- [ ] `GameplayAPI.start()` вызывается при начале геймплея
- [ ] `GameplayAPI.stop()` вызывается при паузе/меню/конце

---

## 4. Промо-материалы (п. 5.1.1)

- [ ] Скриншоты содержат >= 70% реального геймплея
- [ ] Нет внешних элементов (стоковые фото, AI-арт без элементов игры)
- [ ] Мобильные скриншоты — реальный мобильный вид игры
- [ ] ПК скриншоты — реальный десктопный вид игры
- [ ] Иконка отражает стиль игры
- [ ] Обложка (800x470) — геймплей или ключевые элементы

---

## 5. Общие проверки UI

### Текст
- [ ] Минимальный размер шрифта >= 11px на мобильных (п. 1.8)
- [ ] Текст читаемый на всех фонах (контраст)
- [ ] Длинные строки не ломают лейаут (overflow/ellipsis)
- [ ] Все строки локализованы (нет RU-only текстов при EN)

### Кнопки и интерактив
- [ ] Все кнопки >= 44x44px touch target на мобильных
- [ ] Нет мёртвых зон (кнопка видна но не кликается)
- [ ] Hover-эффекты на десктопе
- [ ] Active/pressed состояния на мобильном
- [ ] Disabled кнопки визуально отличаются

### Наложения и z-index
- [ ] Попапы не перекрываются HUD
- [ ] Toast-уведомления видны и не мешают
- [ ] Рекламный overlay (sticky) не перекрывает UI
- [ ] Нет z-index конфликтов

### Скроллинг
- [ ] Длинные списки скроллируются
- [ ] Нет bounce-scroll на body (overscroll-behavior:none)
- [ ] Скроллбары видны или тонкие, не уродливые

---

## 6. Адаптивность экрана

- [ ] `#game` заполняет экран на мобильных (100vw x 100dvh)
- [ ] На десктопе соотношение сторон <= 1:2
- [ ] Нет белых полос по краям
- [ ] Корректное поведение при изменении размера окна
- [ ] `viewport-fit=cover` + safe-area-inset для notch-устройств

---

## Процедура проверки

1. **Десктоп 1280x800** — пройти все экраны: title → карта → торговля → событие → результат → rescue
2. **Мобиль 375x812** — то же самое
3. **Мобиль landscape 812x375** — хотя бы title + карта
4. **Планшет 768x1024** — хотя бы title + карта
5. **EN язык** — добавить `?lang=en`, проверить все экраны
6. **Скриншоты** — сделать на каждом шаге, сравнить с промо-материалами
