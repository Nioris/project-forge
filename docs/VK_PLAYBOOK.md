# VK Mini Apps — Playbook для оператора

Пошаговый операционный гайд от «ничего нет» до «опубликовано в каталоге ВК».
Рассчитан на 1-2 вечера работы при готовой HTML5-игре.

---

## Предварительные требования

- [ ] Аккаунт ВК (можно личный)
- [ ] Готовая HTML5-игра/приложение с относительными путями
- [ ] Node.js ≥ 18
- [ ] Этот форк Project Forge с развёрнутыми VK-скилами
  (см. `patches/APPLY_PATCHES.md`)

---

## Фаза 1 · Создание приложения в VK (5 минут)

1. Зайти: **dev.vk.com** → залогиниться
2. **Мои приложения** → **Создать приложение**
3. Выбрать тип:
   - **Встраиваемое приложение (IFrame)** — универсальный выбор для
     HTML5-игры или приложения с собственным хостингом
   - **Мини-приложение (VK Mini App)** — если планируете хостить у ВК
     через `vk-miniapps-deploy`
4. Название: временное, позже изменится (оно не видно юзерам до публикации)
5. Платформа: **Веб** → подтвердить

→ Получаем:
- **App ID** (число вида `51234567`) — положить в `config.js` как `VK_APP_ID`
- **Защищённый ключ** (`Settings → Защищённый ключ`) — положить в `.env`
  как `VK_CLIENT_SECRET`. В клиентский код НЕ вставлять.

## Фаза 2 · Интеграция VK Bridge в игру (30–60 минут)

### 2.1 Скопировать шаблоны

```bash
cp templates/html5/vk-bridge-wrapper.js path/to/game/
cp templates/html5/vk-init-snippet.html path/to/game/index.html  # как опора
```

### 2.2 Промпт в Claude Code

```
Прочитай скилы vk-sdk-integration и vk-release. Прочитай templates/html5/vk-bridge-wrapper.js и vk-init-snippet.html. Интегрируй VK Bridge в игру в папке path/to/game: подключи wrapper в index.html, найди все localStorage и замени на VKApp.storageGet/Set, добавь VKApp.init() как первый вызов, подключи colbэки setOnPause/setOnResume к игровому лупу. Если есть экраны рекламы — замени на VKApp.showRewarded / VKApp.showInterstitial с cooldown. После этого запусти node scripts/verify-vk.mjs path/to/game и исправь все FAIL.
```

### 2.3 Локальная проверка

Открыть `index.html` в браузере — игра должна запуститься в dev-mode (без VK):
- Splash исчезает
- Storage работает через localStorage
- Реклама эмулируется alert'ом
- Покупка эмулируется confirm'ом

Если что-то не работает — читать консоль. Частые ошибки:
- vk-bridge не подгрузился (проверить `<script src>` и интернет)
- Пути к ассетам абсолютные (`/images/...` вместо `./images/...`)

## Фаза 3 · Хостинг (15 минут)

### Вариант А · Бесплатный хостинг VK

1. Создать `vk-hosting-config.json` в корне проекта:

```json
{
  "static_path": ".",
  "app_id": "ВАШ_APP_ID",
  "endpoints": {
    "mobile": "index.html",
    "mvk": "index.html",
    "web": "index.html"
  }
}
```

`static_path: "."` для single-file HTML.
`static_path: "dist"` если используете сборщик (Vite/Webpack).

2. В `package.json` (если есть):
```json
{
  "homepage": "./",
  "scripts": {
    "deploy:vk": "vk-miniapps-deploy"
  }
}
```

3. Установить и задеплоить:
```bash
npm install -g @vkontakte/vk-miniapps-deploy
vk-miniapps-deploy
# При первом запуске попросит залогиниться через VK
# Результат: бессрочная ссылка вида https://prod-app51234567-xxxx.pages-ac.vk-apps.com
```

### Вариант Б · Свой HTTPS-хостинг

1. Собрать/выложить файлы на любой HTTPS с валидным SSL
   (Cloudflare Pages, GitHub Pages, Timeweb, собственный VPS)
2. Проверить открытие URL в обычном браузере — должно работать в dev-mode
3. Перейти к Фазе 4

## Фаза 4 · Настройка приложения в кабинете (10 минут)

dev.vk.com → ваше приложение → **Настройки**:

| Поле | Что вписать |
|------|-------------|
| Адрес приложения (iframe) | URL хостинга из Фазы 3 |
| Мобильный адрес | тот же URL |
| Адрес приложения Android | тот же URL |
| Адрес приложения iOS | тот же URL |
| Открытый API | включить если планируете вызывать VK API |

Отдельная вкладка **«Подписи запросов»**:
- Включить «Проверять подпись запросов» если серверная часть проверяет `sign`

Отдельная вкладка **«Платежи»** (если есть покупки):
- Включить платежи
- **Адрес callback-сервера** — HTTPS эндпойнт, принимающий POST с полями:
  - `notification_type=get_item` → сервер отвечает деталями товара
  - `notification_type=order_status_change` → сервер выдаёт товар, отвечает 200
- Настроить **Тестеры**: добавить свой VK ID + любого тестера.
  У каждого тестера на счету должен быть ≥ 1 голос
  (голоса при покупке не списываются).

## Фаза 5 · Тестирование на всех платформах (30 минут)

ОБЯЗАТЕЛЬНО проверить перед отправкой на модерацию:

### 5.1 Мобильный веб
```
https://m.vk.com/app{APP_ID}
```
Открыть на телефоне или в мобильной эмуляции Chrome DevTools.

### 5.2 Android приложение ВК
- Открыть приложение ВК
- Слева: Игры → Искать по ID → ввести ваш App ID
- Запустить

**Если не открывается на Android** — 90% причина в том, что `VKWebAppInit`
не вызывается первым. Читайте секцию «#1 Причина реджекта» в
`vk-sdk-integration/SKILL.md`.

### 5.3 Desktop веб
```
https://vk.com/app{APP_ID}
```

### 5.4 Чеклист во время теста

- [ ] Сплэш исчезает за 3–5 секунд
- [ ] Звук играет и глушится при сворачивании вкладки
- [ ] Свайп вниз на iOS НЕ обновляет страницу
- [ ] Long-press НЕ открывает системное меню
- [ ] Rewarded кнопка видна (если игра с ней) ИЛИ скрыта если нет рекламы
- [ ] Interstitial показывается ТОЛЬКО при переходе между уровнями/меню
- [ ] После interstitial игра не зависает — таймер dt не скачкает
- [ ] Покупка голосов проходит у тестера без списания

## Фаза 6 · Заполнение карточки каталога (1–2 часа)

Промпт в Claude Code:

```
Прочитай скил fill-vk. Создай в StoreData/vk/ все материалы для карточки каталога VK Mini Apps: description.md с названием, short description, full description, категорией и 5 тегами. Шаблоны для иконок 278×278, 278×370, 192×192 (промпты для Midjourney / Кандинский). Баннер 1120×800. Чеклист SUBMISSION_CHECKLIST.md.
```

Что нужно своими руками:
- Иконки: либо нарисовать/сделать в редакторе, либо сгенерировать по промпту
- Скриншоты: запустить игру, нажать Print Screen, обрезать до нужных размеров
- Политика конфиденциальности: можно взять шаблон с
  [privacypolicies.com](https://www.privacypolicies.com) или написать самим

## Фаза 7 · Отправка на модерацию

1. dev.vk.com → ваше приложение → **Информация для каталога**
2. Заполнить ВСЕ поля из `StoreData/vk/description.md`
3. Загрузить иконки и скриншоты
4. Выбрать категорию и теги
5. Указать возрастное ограничение
6. Сохранить → **«Отправить на модерацию»**

**Срок:** 1–3 рабочих дня.
**Если реджект** — ВК пришлёт текстовое замечание. Промпт для фикса:

```
Прочитай скил vk-release секцию "10 Частых Причин Реджекта". Замечание модерации: [ТЕКСТ ЗАМЕЧАНИЯ]. Разбери, исправь код и материалы карточки, после — node scripts/verify-vk.mjs должен показать 0 FAIL. Подготовь ответ модерации с объяснением внесённых изменений.
```

## Фаза 8 · После публикации

### Мониторинг

- **Аналитика:** dev.vk.com → приложение → Статистика (DAU, MAU, retention)
- **MyTracker** (рекомендует VK): добавить `VKWebAppTrackEvent` для событий:
  ```javascript
  await bridge.send('VKWebAppTrackEvent', {
    event_name: 'level_complete',
    event_params: { level: 5, score: 1234 },
  });
  ```
- **Отзывы:** dev.vk.com → приложение → Отзывы — отвечать в течение 24 часов

### Обновления

1. Изменили код → deploy того же URL (или повторный `vk-miniapps-deploy`)
2. Версия бампается автоматически — обновления применяются мгновенно
3. Для крупных апдейтов — написать в Changelog карточки

### Вывод денег (если монетизация)

- Голоса → рубли через **AppsCentrum** (партнёр ВК)
- Комиссия ВК: 45% от выручки
- Минимальная сумма вывода: ~1000 ₽
- Нужно: ИП/самозанятый/юрлицо + договор

## Частые вопросы

**Q: Можно ли то же приложение одновременно в ВК и в Яндекс Играх?**
A: Да. Это разные SDK — одна кодовая база, два wrapper'а через feature-flag.
См. `templates/html5/yandex-sdk-wrapper.js` + `templates/html5/vk-bridge-wrapper.js`
и `const PLATFORM = detectPlatform()` в бутстрапе.

**Q: Какая разница между VK Mini Apps и Direct Games?**
A: Сейчас — никакой для HTML5. Direct Games был отдельной платформой для
игр с 2017, но методы VK Bridge общие. При создании приложения выбирайте
«Встраиваемое приложение» или «Мини-приложение» — оба поддерживают игры.

**Q: Работает ли на Одноклассниках (OK)?**
A: Да. Приложения из VK Mini Apps автоматически доступны в каталогах
OK, Mail.ru, браузера Atom, RuStore. Отдельной сборки не нужно.

**Q: Сколько реально зарабатывают приложения в ВК?**
A: По открытым жалобам разработчиков (comnews 2021, актуально на 2026):
небольшая игра 15-16 тыс. ₽/мес до вычета 45% комиссии VK = ~8 тыс. в кармане.
Средние игры — 50-200 тыс. ₽/мес. Топы — 1-5 млн ₽/мес.

**Q: Нужен ли сервер?**
A: Не обязательно, но:
- Для платежей — ДА (callback URL)
- Для проверки sign — ДА (если доверяем юзеру-паранойя)
- Для leaderboards кросс-платформенных — ДА
- Для простой игры без этого — нет, можно обойтись VK Storage
