# Store Listing — SEO-описания для магазинов

## Правило
Описание пишется НЕ для разработчика, а для ПОЛЬЗОВАТЕЛЯ который ищет приложение в магазине. Он не знает технических терминов. Он хочет понять за 3 секунды — ЧТО это и ЗАЧЕМ ему.

## Step 1: Анализ приложения

Перед написанием — ответь на вопросы:
1. Что делает? (одно предложение)
2. Для кого? (целевая аудитория)
3. Чем лучше конкурентов? (3 УТП)
4. Какие проблемы решает?
5. Главные фичи (5-7 штук)

## Step 2: Подбор ключевых слов

Подобрать 15-20 ключевых слов которые пользователь вводит в поиск:

```
ПРАВИЛА:
- Думай как пользователь, НЕ как разработчик
- "открыть документ" а не "document viewer"
- "фонарик" а не "flashlight utility"
- Включай синонимы: "заметки" + "записи" + "записная книжка"
- Включай задачи: "открыть pdf" + "читать docx" + "csv таблица"
- Включай контекст: "без интернета" + "офлайн" + "бесплатно"
```

Пример для UniDocs:
```
Основные: просмотр документов, открыть pdf, читалка файлов
Форматы: docx, xlsx, csv, pptx, pdf, txt, markdown
Действия: открыть файл, просмотреть документ, читать офлайн
Фичи: сканер документов, конвертер файлов, ai помощник
Контекст: без интернета, бесплатно, для андроид
```

## Step 3: Написание для RuStore

### Название (до 30 символов)
```
ФОРМУЛА: [Суть] — [Уточнение]
ПРИМЕРЫ:
  UniDocs — Все документы
  MultiTool — 13 утилит  
  FileView — CSV и JSON
  Записочная — Заметки офлайн

НЕ НАДО:
  ❌ UniDocs - Universal Document Viewer Pro  (английский, длинно)
  ❌ Просмотрщик документов PDF DOCX XLSX CSV  (спам ключевиков)
  ❌ MultiTool Pro v2.1  (версии не нужны в названии)
```

### Короткое описание (до 80 символов)
```
ФОРМУЛА: [Глагол] + [что делает] + [ключевая фича]

ПРИМЕРЫ:
  "Открывай PDF, DOCX, XLSX и другие документы. Работает без интернета."
  "13 инструментов: фонарик, компас, линейка, шумомер и другие."
  "Просматривай CSV, JSON, XML файлы. Таблицы, деревья, поиск."
  "Создавай заметки мгновенно. Сохраняются даже без интернета."

НЕ НАДО:
  ❌ "Лучшее приложение для документов"  (пустое хвастовство)
  ❌ "App for viewing documents on your phone"  (английский)
```

## Step 4: Написание для Яндекс Игр

Яндекс Игры имеют специфику:
- Описание КОРОЧЕ (до 1500 символов)
- Критически важно: ЧТО ЗА ИГРА за 1 предложение
- Механики и управление — обязательно
- НЕ писать про скачивание (это веб-игра)

```markdown
{Жанр} игра: {одно предложение что делаешь}.

🎮 КАК ИГРАТЬ
• {Управление — клавиши/тап/свайп}
• {Основная механика}
• {Цель}

⚡ ОСОБЕННОСТИ
• {Фича 1}
• {Фича 2}
• {Фича 3}

🏆 СОРЕВНУЙСЯ
• Лидерборд — стань лучшим среди всех игроков
• {Достижения если есть}
```

## Step 5: Чеклист качества

```
[ ] Первое предложение — понятно ЧТО это за 3 секунды
[ ] Нет английских слов (кроме названий форматов: PDF, DOCX)
[ ] Нет технического жаргона (нет "API", "SDK", "framework")
[ ] Ключевые слова вплетены естественно (не спам)
[ ] Эмодзи-заголовки разбивают стену текста
[ ] Фичи описаны через пользу (не "есть компас" а "точный азимут")
[ ] Есть призыв к действию в конце
[ ] Длина в рамках лимита площадки
[ ] Описание на русском (не перевод с английского)
[ ] Нет обещаний которые приложение не выполняет
```

## Non-Negotiable
- [ ] Описание на РУССКОМ, человеческим языком
- [ ] Первое предложение отвечает на "что это и зачем"
- [ ] 5-7 ключевых слов вплетены в текст естественно
- [ ] Структура с эмодзи-блоками (не стена текста)
- [ ] Нет пустого хвастовства ("лучший", "уникальный", "№1")
- [ ] Фичи через пользу пользователя
