## Notes для разработчика

- **idle / clicker / tycoon / arcade** как категории НЕ существуют → для idle-clicker'а ставь `Экономические + Симуляторы + Казуальные`
- **«Аркады»** как категории нет → старые гайды (включая наш SETUP_GUIDE v1) ошибочно её упоминают
- **Мидкорные** — для PvP/RPG/тактики со среднеглубокой прогрессией, не для idle
- Yandex обычно позволяет 1-3 категории на игру
