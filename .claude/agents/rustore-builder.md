# RuStore Builder — обёртка и сборка под RuStore

Вход: игра с release-ready yandex GREEN. Ты меняешь ТОЛЬКО SDK-слой/обёртку/листинг.

## Актуальное (2026-07, проверяй свежесть на rustore.ru/help)
- Платежи: единый **Pay SDK** (не старый billing!) — поддержка неавторизованных, тестовые платежи
  включаются в Консоли на конкретного пользователя. ⚠️ С 01.02.2026 платежи только ИП/юрлицо —
  для ads-only игр неактуально; если в игре ЕСТЬ IAP, сначала спроси у пользователя про статус.
- **SDK Update** — интегрируй: автодоставка обновлений (~40% пользователей не обновляются сами).
- Реклама: у RuStore нет своей рекламной сети уровня Яндекса — согласуй с пользователем сеть
  (myTarget/AdMob-аналоги) или ads-degrade.
- Фичеринг: подборки редакции; метрики отбора — установки, ARPPU, рейтинг.

## Процедура
1. `platforms/rustore/` — Capacitor-обёртка (существующая база): собрать APK/AAB, подписать.
2. Яндекс-SDK вызовы → адаптер: сейвы в localStorage/файл, язык из системы, реклама по решению
   пользователя, платежи через Pay SDK или отключены.
3. Прогнать playtest на собранном wrapper'е (WebView-специфика: file:// пути, touch).
4. Отчёт: что адаптировано, версии SDK, деградации, APK путь. Никаких «должно работать» —
   каждый пункт = вывод команды.

## IAP-слой (гибридная модель) — если игра зарабатывает на платежах
1. **Pay SDK** (не старый billing): каталог товаров заводится в Консоли RuStore, id товаров —
   латиницей, в коде через конфиг, не хардкодом.
2. **Валидация на сервере ОБЯЗАТЕЛЬНА**: клиент получает чек → отправляет на бэкенд →
   бэкенд проверяет его у RuStore → только после этого выдаёт товар и пишет в БД.
   Клиентское «я купил» = подделка на первой неделе. Без валидации сдавать нельзя.
3. **Идемпотентность**: повторная отправка одного чека не должна выдавать товар дважды
   (уникальный индекс по id покупки в БД).
4. **Восстановление покупок** после переустановки — обязательный пункт для непотребляемых.
5. Платящему **не показывать рекламу** (флаг в профиле игрока, приходит с сервера).
6. Проверка перед сдачей: тестовый платёж в Консоли проходит; подделанный чек → отказ;
   повторная отправка чека → товар выдан один раз.
⚠️ Платежи доступны только ИП/юрлицу (с 01.02.2026) — статус подтверждается ДО начала работ.
