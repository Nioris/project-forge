# VK Mini Apps — Заполнение карточки

## Purpose
Собрать весь набор материалов для публикации в каталоге VK Mini Apps:
описания, графика, категория, теги, возрастная метка. Без этого приложение
висит «в разработке» и недоступно миллионной аудитории.

## Где это заполняется
`dev.vk.com` → ваше приложение → раздел **«Информация для каталога»**.

После заполнения → кнопка **«Отправить на модерацию»**. Срок: 1–3 рабочих дня.

## Что нужно подготовить (StoreData/vk/)

### 1. Текст (`StoreData/vk/description.md`)

```markdown
# Название (до 40 символов)
<!-- Без ALL CAPS, без эмоджи, без возрастного рейтинга, без "VK" в названии -->
Название Приложения

# Короткое описание (до 100 символов)
<!-- Показывается в карточке каталога рядом с иконкой. ASO-оптимизация. -->
Одна мощная фраза про суть. Ключевые слова в начале.

# Полное описание (до 4000 символов)
<!-- Разрешён markdown-подобный текст с переносами. -->
Что делает приложение. Какие проблемы решает. Какие возможности.

## Возможности
- Фича 1
- Фича 2
- Фича 3

## Как пользоваться
1. Шаг
2. Шаг

## Обратная связь
Ссылка на сообщество / email для поддержки.
```

**Требования к названию (п. 5.12 аналога правил ВК):**
- Длина 3–40 символов
- Без эмоджи
- Без возрастного рейтинга в названии
- Без полностью заглавных букв
- Не должно нарушать товарные знаки
- Проверить уникальность поиском по каталогу VK Mini Apps

### 2. Категория (выбрать ОДНУ)

Список категорий VK Mini Apps (актуален на 2026):

- **Игры** (Games)
- **Дейтинг и знакомства**
- **Развлечения** (тесты, гадания, мемы)
- **Для друзей** (коллективные активности)
- **Здоровье и спорт**
- **Образование**
- **Покупки**
- **Еда и напитки**
- **Путешествия и транспорт**
- **Бизнес**
- **Финансы**
- **Утилиты**
- **Новости и СМИ**

**Правило:** категория определяется по **основной механике**, не по сеттингу.
Пример: квиз с историческим контентом → «Развлечения», НЕ «Образование».

### 3. Теги (до 5)

Свободные теги, по которым приложение будет искаться:

```
Пример для idle-clicker: клики, кликер, тайкун, бесплатно, казуальные
Пример для пазла: головоломка, логика, одиночная, офлайн, бесплатно
```

Правила:
- Каждый тег — одно-два слова на русском
- Без хэштегов (#)
- Без повторов между собой
- Без названий конкурентов

### 4. Иконки

| Файл | Размер | Формат | Где используется |
|------|--------|--------|------------------|
| `icon-278.png` | 278×278 | PNG, прозрачный или фон | Карточка каталога, список «Мои» |
| `icon-278x370.png` | 278×370 | PNG | Альтернативная плитка в категориях |
| `icon-192.png` | 192×192 | PNG | Favicon и миниатюры |

**Правила иконки (жёсткие):**
- НЕ скриншот интерфейса
- НЕ текст во всю иконку (логотип + графика допустимы)
- НЕ использовать копии чужих иконок или персонажей
- Чистые края, читается на тёмном И светлом фоне
- Читается в 48×48 (мелкий размер в списках)

### 5. Баннер

| Файл | Размер | Где |
|------|--------|-----|
| `banner-1120x800.png` | 1120×800 | Топ раздела «Интересное», промо-карточки |

- >= 70% площади — элементы из приложения
- Текст на баннере — опционально, до 4 слов максимум
- Не должен копировать дизайн других приложений

### 6. Скриншоты

**Мобильные (ОБЯЗАТЕЛЬНО минимум 2):**
- Размер: 420×280 или 360×640 (портрет) / 640×360 (ландшафт)
- Формат: PNG или JPG
- Количество: 2–5

**Desktop (рекомендуется):**
- Размер: 1440×920
- 2–4 штуки

**Правила (п. 5.1.1 аналог):**
- >= 70% — реальный геймплей / UI приложения
- НЕ стоковые изображения
- НЕ скриншоты других приложений
- НЕ системные UI (статус-бар, батарея)
- Использовать marketing-билд с читами для красивого прогресса

### 7. Возрастной рейтинг

Выбирается в карточке. Обычно одно из:
- **6+** — бесплатные казуальные без насилия
- **12+** — элементы фэнтезийного насилия, платёжные функции
- **16+** — романтические элементы, реалистичное насилие
- **18+** — только для взрослых (требует дополнительного согласия VK)

**Важно:** если приложение использует:
- VKWebAppShowOrderBox (покупки) → минимум **12+**
- Соцфункции (приглашения) → минимум **6+** (не для детей младше)

### 8. Скрины для поддержки модерации

Модерация может запросить дополнительно:
- Demo-видео 15–30 сек, MP4, до 20 МБ
- Политика конфиденциальности (URL или файл .md в разделе)

## Чеклист SUBMISSION_CHECKLIST.md (обязательный)

```markdown
# Чеклист модерации VK

## Контент
- [ ] Название уникально в каталоге VK Mini Apps
- [ ] Название 3–40 символов, без ALL CAPS и эмоджи
- [ ] Короткое описание ≤ 100 символов
- [ ] Полное описание ≤ 4000 символов
- [ ] Категория соответствует основной механике
- [ ] 3–5 тегов, без повторов и конкурентов

## Графика
- [ ] icon-278.png 278×278, читается на 48×48
- [ ] icon-278x370.png 278×370
- [ ] icon-192.png 192×192
- [ ] banner-1120x800.png — элементы из приложения ≥ 70%
- [ ] 2+ мобильных скриншота 420×280 или 360×640
- [ ] 2+ desktop скриншота 1440×920 (если desktop версия работает)
- [ ] Ни один скриншот не содержит системного UI

## Техническое
- [ ] URL HTTPS, доступен внешне
- [ ] На всех 3 платформах открывается (web/mvk/mobile_android)
- [ ] VKWebAppInit вызывается
- [ ] Нет локальных URL (localhost, file://)
- [ ] Политика конфиденциальности указана

## Монетизация
- [ ] Если есть покупки — зарегистрированы item_id в кабинете
- [ ] Callback URL для платежей настроен и отвечает 200
- [ ] Если есть реклама — CheckNativeAds работает на всех платформах
- [ ] Возрастная метка соответствует контенту

## Юридическое
- [ ] Правообладатель имеет все права на контент
- [ ] Нет нарушения товарных знаков
- [ ] Нет запрещённого контента (азартные игры на реальные деньги, 18+, политика)
```

## Частые реджекты по карточке

1. **Иконка текстовая** — надпись во всю иконку без графики
2. **Скриншоты — скриншоты другой игры или стоковые**
3. **Описание противоречит функционалу** — обещано «крутая RPG», фактически кликер
4. **Callback URL платежей не отвечает** — автоматический реджект
5. **Название содержит "VK" / "ВКонтакте"** — нарушение бренд-правил
6. **Политика конфиденциальности отсутствует** при наличии логина/покупок

## Non-Negotiable
- [ ] Никогда не отправлять на модерацию без SUBMISSION_CHECKLIST.md
- [ ] Всегда проверить уникальность названия поиском
- [ ] Все скриншоты — из реального билда, не из промо-рендера
- [ ] Категория = основная механика, не сеттинг
- [ ] Если нет desktop-версии — не загружать desktop-скриншоты (лучше меньше да лучше)
