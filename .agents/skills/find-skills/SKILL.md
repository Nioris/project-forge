# $find-skills — сперва поискать готовое, потом писать своё

> Основано на `find-skills` из [vercel-labs/skills](https://github.com/vercel-labs/skills) (28k★).
> `npx skills` — менеджер пакетов открытой экосистемы скилов, ставит в 18+ агентов
> (Claude Code, Codex, Cursor, opencode). Каталог: https://skills.sh/

## Когда применять
Пользователь спрашивает «а есть скил для X», «как сделать X» (где X — типовая задача),
хочет расширить возможности агента — ИЛИ ты сам собрался писать новый скил под задачу,
которая наверняка уже решена кем-то.

**Правило движка: перед созданием нового скила — проверь каталог.** Своё пишем только для
того, что специфично для нас (Яндекс/RuStore, наш конвейер, наши игры). Общее — берём готовое.

## Команды
```
npx skills find <запрос>                       # поиск по каталогу
npx skills add <owner>/<repo> --list           # что есть в репозитории
npx skills add <owner>/<repo> --skill <имя> -g -y   # поставить глобально, без вопросов
npx skills list · npx skills update · npx skills remove
```
`-g` — на пользователя (все проекты), без него — в текущий.

## Гигиена отбора (не рекомендовать по одной выдаче поиска)
| Критерий | Порог |
|---|---|
| Установки | предпочитать 1000+; меньше 100 — с осторожностью |
| Источник | официальные (anthropics, vercel-labs, microsoft) надёжнее незнакомых авторов |
| Звёзды репозитория | меньше 100 — скептически |
| Соответствие | скил должен решать ИМЕННО задачу, а не «примерно про то же» |

Нашёл подходящее — покажи пользователю: что делает, сколько установок, команда установки.
Не нашёл — скажи одной строкой и делай задачу сам, не изобретая скил ради скила.

## Что стоит поставить нам (проверено, официальные источники)
```
npx skills add anthropics/skills --skill frontend-design -g -y
npx skills add vercel-labs/agent-skills --skill web-interface-guidelines -g -y
npx skills add mattpocock/skills --skill grilling -g -y
```
- **frontend-design** (Anthropic) — методика дизайна: калибровка против дефолтов, два прохода,
  signature-элемент. Мы перенесли её содержательно в art-direction; установка даёт оригинал;
- **web-interface-guidelines** (Vercel) — 100+ правил интерфейса: доступность, производительность,
  UX. Прямо в нашу больную точку с экранами;
- **grilling** (Matt Pocock) — у нас уже установлен как `$grilling`.

⚠️ Ставить чужие скилы пачками не надо: каждый попадает в список автодополнения и конкурирует
за срабатывание с нашими. Берём точечно, под названную задачу.
