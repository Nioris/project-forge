# $seasonal-event — тематические события Яндекс Игр как рычаг трафика

Яндекс регулярно проводит тематические события: игры с тематической активностью получают бейдж
«Акция» в ленте и на «Мои игры» + размещение в разделе «Скидки и акции» → бесплатный трафик.
Примеры 2026: летний сезон (16–19 июня), День Головоломки (13–16 июля).

## Процедура

### 1. Проверить актуальный календарь (события анонсируются заранее)
Источники анонсов (проверять web-поиском/fetch при каждом запуске — календарь живой):
- Telegram-канал: t.me/yangamesdevnews
- Блог: yandex.ru/blog/gamesfordevelopers
Найти: ближайшее событие, даты, тема. ⚠️ Заявки закрываются ЗА НЕСКОЛЬКО ДНЕЙ до старта;
модерация промоакции — до 3 рабочих дней, не работает в выходные/праздники/ночью. Считать дедлайн
подачи = старт − 4-5 рабочих дней.

### 2. Оценить соответствие игры теме
Событие тематическое (головоломки, лето, Новый год...). Игра должна честно иметь отношение к теме
ИЛИ получить тематическую активность. Натягивать нельзя — модерация промоакции проверяет.

### 3. Сгенерировать тематическую активность В ИГРЕ (код)
Минимальная честная активность (выбрать по жанру):
- временный тематический режим/уровень/набор задач;
- тематический скин/декор + бонус за вход в дни события;
- событие-челлендж с наградой (x2 доход, уникальный предмет) на даты события.
Требования к реализации: активность видна с главного экрана; включается по датам (проверка
локальной даты, БЕЗ внешних запросов); после события игра остаётся валидной (событие тихо гаснет).
⚠️ После правок — стандартный цикл: пересборка → $release-ready yandex (событие не должно ломать
пробы A–G) → обновление билда в Консоли.

### 4. Подготовить промоакцию (Консоль — руками пользователя)
Сгенерировать пользователю готовый текст: название акции, описание активности, даты.
Путь: Консоль → игра → вкладка «Промоакции» → «Создать промоакцию» → заполнить → отправить.
Напомнить: Яндекс Метрика — чтобы оценить эффект события.

### 5. После события
Снять бейдж-логику не нужно (гаснет по датам). Зафиксировать в metrics.md: трафик до/во время/после
— события с хорошим эффектом повторять на следующих датах календаря.

## Rating red-line (2.13, ужесточён 07.2026)
Рейтинг ≤30 три недели подряд → игра СНИМАЕТСЯ с публикации. События — один из инструментов
реанимации: свежая активность + приток игроков поднимает рейтинг. Если у игры рейтинг падает к 30 —
ближайшее тематическое событие становится приоритетом, не опцией.
