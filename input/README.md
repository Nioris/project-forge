# input/ — твои исходные игры и приложения

Положи сюда **каждую игру в отдельную подпапку**:

```
input/
├── my-platformer/
│   ├── index.html
│   ├── game.js
│   └── assets/
├── my-idle-clicker/
│   └── ...
└── ...
```

Пайплайны (`/improve`, `/convert`, `/vk-release`, `/yandex-release`) работают так:

- **С аргументом** — обрабатывают указанную папку:
  `Прочитай скил vk-release. Обработай input/my-platformer ...`
- **Без аргумента** — сканируют `input/` и берут первую необработанную.

Итог пайплайн кладёт в `output/{name}-{platform}/` — оригиналы в `input/`
остаются нетронутыми.

## Что сюда НЕ кладётся
- Сама обёртка `vk-bridge-wrapper.js` — она в `templates/html5/`
- Скилы и документация — в `.claude/` и `docs/`
- Собственно код Project Forge — в `src/` (если ты расширяешь сам форк)
